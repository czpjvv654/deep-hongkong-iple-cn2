## 深港专线网络是什么，和普通香港线路差在哪

深港专线是连接深圳与香港的点对点专用数据通道，走的是物理隔离的独享链路，最常见的形态叫IPLC（国际私有租用线路）。它依托海底光缆或跨境光纤，把深圳的节点和香港的节点直连，数据全程不经过公网路由，路径固定。这就是延迟低、波动小的根源。

CN2本质还是公网优化线路，高峰期大家一起挤一条路；专线相当于单独给你修了一条。差距有多大，看数据：

| 指标 | 传统CN2线路 | 深港IPLC专线 |
| --- | --- | --- |
| 平均延迟 | 25–60ms | 2–5ms |
| 高峰期波动 | ±40ms | ±2ms |
| 可用性 | 99.5% | 99.99% |
| 带宽保障 | 共享 | 独享 |

还有一个常见混淆值得说开：深港专线和VPN的区别。VPN是在公网上建加密隧道，底层路径照样不固定，加密只发生在应用层；专线是物理层独享，延迟、稳定性、安全性都高一个级别，价格也高一个级别。

1. **不同时段实测延迟。** 宣传的2ms是端内理想值，你要确认的是晚高峰的抖动幅度。专线承诺的±2ms波动和公网±40ms的波动，体验差距就在这里。

## 常见问题

**深港专线和VPN有什么区别？**
专线是物理层独享链路，VPN是公网上的加密隧道。专线在延迟、稳定性、安全性上都明显优于VPN，代价是价格高得多。

**深港专线延迟多少算正常？**
IPLC专线端内延迟一般在2–5ms；普通CN2优化线路是25–60ms，晚高峰波动更大。香港机器ping值长期高于60ms，线路本身就有问题。

**成本是怎么构成的？**
主要三块：带宽费用、端口费用、维护费用。评估总成本时要把业务数据量和峰值流量一起算进去，只看单价容易低估。

**独享IPLC为什么这么贵？**
带宽物理独享，一条线只服务一家客户，运营成本摊不到别人头上。1000元/月档提供独享带宽和无限流量，价格反映的是资源独占。
